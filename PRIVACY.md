# YT Sender – Privacy Policy

YT Sender does not collect, transmit, or sell personal data. 

All settings (server URL, behavior preferences, optional credentials) are stored locally using Chrome storage. 

On user action, the extension sends the current page URL to the user-configured YTdownloader origin, 
and—if authentication is enabled—submits the provided credentials only to that origin for the sole purpose of authentication. 

No analytics or third-party data sharing is performed.
