YT Downloader – Options

lightweight helper for your self-hosted downloader

This extension adds a context-menu and toolbar action to send video links to your own YTdownloader instance. You’ll need a running server. See the YTdownloader docs.

Connection
Use full origin (https://host[:port]). No trailing slash.
Toolbar click
Context-menu on video links
Authentication
If enabled, the extension logs in before sending links.
Additional sites
Patterns follow Chrome’s match pattern rules. Tip: use *://*.example.com/* for all schemes & subdomains.
